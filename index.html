Como configurar (uma vez)

  1. Acesse Google Cloud Console e crie um projeto.
  2. Ative YouTube Data API v3.
  3. Configure a tela de consentimento OAuth e crie um ID do cliente OAuth do tipo Aplicativo da Web. Em “Origens JavaScript autorizadas”, adicione o endereço onde este arquivo será hospedado (por exemplo, seu domínio). Para teste local, use um servidor local, não abra o arquivo com duplo clique.
  4. Copie o ID do cliente e cole no campo desta página. Não é necessário editar o código.
  5. Em “Origens JavaScript autorizadas”, adicione exatamente http://localhost:8765. Se o app OAuth estiver em modo de teste, adicione sua conta Google como usuário de teste.

Este protótipo usa a API oficial do YouTube. O Google pode exigir configuração/verificação do consentimento. Nunca compartilhe seu segredo OAuth; este app usa apenas o ID público do cliente.
