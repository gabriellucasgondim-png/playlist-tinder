Conectar playlist

Entre com sua conta Google e cole o link da playlist do YouTube Music. Deslize para a direita para manter e para a esquerda para remover. Nada muda na playlist até você tocar em salvar.

Como configurar o ID OAuth (uma vez)
  1. Abra o Google Cloud Console e crie um projeto.
  2. Ative a YouTube Data API v3.
  3. Configure a tela de consentimento e crie um ID do cliente OAuth do tipo Aplicativo da Web.
  4. Em “Origens JavaScript autorizadas”, adicione o endereço onde este arquivo está hospedado (ex.: seu GitHub Pages). Se o app estiver em modo de teste, adicione sua conta como usuário de teste.
Sobre os anúncios (YouTube Premium)

O player usa o domínio normal do YouTube para reconhecer seu Premium. Para funcionar sem anúncios, você precisa estar logado no YouTube neste mesmo navegador e o navegador não pode bloquear cookies de terceiros (Safari/iPhone e Brave costumam bloquear). Não há forma legítima de remover anúncios por conta própria.
